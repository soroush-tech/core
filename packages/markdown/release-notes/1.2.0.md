## @soroush.tech/markdown@1.2.0

Maintenance release — dependency refresh only. No new components, no API or behavior changes.
([#280](https://github.com/soroush-tech/core/pull/280))

### Packaging

- **`mermaid` dependency floor raised `^11.4.0` → `^11.16.1`** — same major, backward compatible.
  It stays lazily imported, so the diagram bundle is still only fetched when a `mermaid` code
  fence renders.
- **`react` and `react-dom` peer floors raised `^19.0.0` → `^19.2.8`.** Still React 19 only —
  the range narrows to the patch line this release is built and tested against.
- **`@soroush.tech/design-system` peer floor moves to `^1.2.0`** with that package's own
  maintenance release, whose React peer floors move in step.

  `eslint-plugin-storybook` `^10.5.0` → `^10.5.6`, `globals` `^17.7.0` → `^17.9.0`,
  `react`/`react-dom` `^19.2.7` → `^19.2.8`, `storybook` `^10.5.0` → `^10.5.6`, `tsdown`
  `^0.22.7` → `^0.22.14`. `jsdom` stays on `^29.1.1` — held repo-wide in `renovate.json`, see
