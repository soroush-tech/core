## @soroush.tech/markdown@1.2.1

Maintenance release — build tooling and a dependency refresh. No public API, behavior, or
emitted-output changes.
([#328](https://github.com/soroush-tech/core/issues/328))

### Packaging

- The workspace replaced ESLint with [oxlint](https://oxc.rs). This package's `eslint.config.js`
  became an `.oxlintrc.json`, and its `lint` script now runs `oxlint --deny-warnings`; the enforced
  rule set is unchanged, including every `react-hooks` rule. Dev-dependency change only — `eslint`
  and its plugins out, `oxlint` in. No runtime or peer dependency changes, and the published
  tarball is unaffected.
- `typescript` moves to `~7.0.2`. It is a dev dependency here, used to typecheck and emit; the
  emitted output is unchanged.
- Dev-dependency bumps: `@storybook/react-vite` and `storybook` `^10.5.6` → `^10.5.8`,
  `@testing-library/jest-dom` `^7.0.0` → `^7.0.1`. No runtime or peer dependency changes, and
  the `@soroush.tech/design-system` peer floor is unchanged.
- `jsdom` stays on `^29.1.1`, held repo-wide in
  [`renovate.json`](https://github.com/soroush-tech/core/blob/main/renovate.json) — see the
  design-system notes for the reason.
