## @soroush.tech/markdown@1.2.2

Maintenance release. Two default placeholders change; no API changes.

### Changed

- `Markdown.Editor`'s default placeholder is `Write your article in Markdown...` and `LiveEdit`'s
  is `Click to start writing...`, each ending in three periods rather than an ellipsis character.
  Both are props: pass your own `placeholder` to keep any other text.

No rendered markdown output, theme slot, or mermaid behavior changed.
