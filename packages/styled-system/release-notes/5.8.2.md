## @soroush.tech/styled-system@5.8.2

Maintenance release - build tooling only. No public API, behavior, or type changes.
([#328](https://github.com/soroush-tech/core/issues/328))

### Packaging

- The workspace moved its formatter from Prettier to `oxfmt`, which wraps multi-line union types
  onto leading-pipe lines. That reformatted the `ObjectOrArray` declaration in `src/types.ts`;
  the type it describes is unchanged. No source, runtime, peer, or dev dependency changes.
- `typescript` moves to `~7.0.2`. It is a dev dependency here, used to typecheck and emit; the
  emitted output is unchanged.
