## @soroush.tech/design-system@1.3.2

Maintenance release — the package gained a Storybook of its own. No public API, behavior, or
emitted-output changes.

### Packaging

- `storybook` no longer delegates to the site's Storybook: the package has its own config in
  [`.storybook/`](https://github.com/soroush-tech/core/tree/main/packages/design-system/.storybook),
  serving only this package's stories against the shipped `baseTheme` on port 6007 — the component
  library is now viewable without the site checked out. `build:storybook` and `test:storybook`
  scripts were added alongside it; the latter runs every story's play function and a11y check.
- New dev dependencies: `@storybook/addon-a11y` `^10.5.7`, `@storybook/addon-docs` `^10.5.7`,
  `@storybook/addon-vitest` `^10.5.7`.
- No runtime, peer, or optional-peer dependency changes. The `files: ["dist"]` allowlist is
  unchanged, so `.storybook/` is not part of the published tarball.
