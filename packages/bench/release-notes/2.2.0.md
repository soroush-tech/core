## @soroush.tech/bench@2.2.0

Maintenance release - dependency refresh only. No public API or behavior changes.
([#280](https://github.com/soroush-tech/core/pull/280))

### Packaging

- Node engine floor raised `>=24.18.0` → `>=24.19.0`. Consumers on Node < 24.19.0 will see an
  engine warning on install; upgrade Node to stay supported.
- Dev-dependency bumps: `@types/node` `^26.1.1` → `^26.1.2`, `eslint` `^10.7.0` → `^10.8.0`,
  `globals` `^17.7.0` → `^17.9.0`, `tsdown` `^0.22.7` → `^0.22.14`. No runtime or peer dependency
  changes.
