## @soroush.tech/bench@2.2.1

Patch release - sandbox image hardening only. No public API or behavior changes.
([#327](https://github.com/soroush-tech/core/pull/327))

### Packaging

- The sandbox image installs its global `tsx` with `--ignore-scripts`, so no dependency lifecycle
  script runs during the image build. esbuild's binary arrives as a platform package, so nothing
  changes at runtime.
- `tsx` is now pinned exactly (`4.23.11`, previously the `^4` range), so rebuilding the image
  always produces the same toolchain.
