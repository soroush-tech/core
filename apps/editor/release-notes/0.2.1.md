## Soroush Editor v0.2.1

Maintenance release — build tooling only. No features, fixes, or behavior changes.
([#328](https://github.com/soroush-tech/core/issues/328))

### Housekeeping

- The workspace moved its formatter from Prettier to `oxfmt`, which wraps multi-line union types
  onto leading-pipe lines. That reformatted the `GistDraftEntry` declaration in
  `src/shared/ipc.ts`; the type it describes is unchanged. No dependency changes.
- The workspace replaced ESLint with [oxlint](https://oxc.rs), and `typescript` moves to `~7.0.2`.
  Both are build-time only; the shipped app is unchanged.
