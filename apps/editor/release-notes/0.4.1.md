## Soroush Editor v0.4.1

Maintenance release - the editor now builds against the published design-system and markdown
packages instead of their old in-repo copies, which moved to their own repository. No intentional
feature or behavior changes.

### Packaging

- `@soroush.tech/design-system` workspace copy (1.3.3) → `2.0.0-alpha.2` from npm. The 2.0
  breaking changes - window-class breakpoints, range-syntax media queries, the popover `Drawer` -
  don't reach the editor: it uses no responsive props and no `Drawer`.
- `@soroush.tech/markdown` workspace copy → `1.2.2` from npm. That release still declares
  `@soroush.tech/design-system` `^1.3.3` as a peer; it resolves to `2.0.0-alpha.2` here, which
  installs with an unmet-peer warning until a markdown release for design-system 2.x.
