## Soroush Editor v0.2.0

First release of the desktop markdown editor — a Gist app for writing markdown, built on
[`@soroush.tech/design-system`](https://github.com/soroush-tech/core/tree/main/packages/design-system)
and [`@soroush.tech/markdown`](https://github.com/soroush-tech/core/tree/main/packages/markdown).
([#295](https://github.com/soroush-tech/core/issues/295))

### Features

- **Markdown editing** — a source editor with formatting toolbar, live preview, and app-level
  undo/redo with the standard shortcuts.
- **Files and gists** — New/Open/Save/Save As through native dialogs, with an unsaved-changes
  guard on close and reload. Sign in to GitHub to list and edit your gists, start new ones, and
  work in an offline draft sandbox — nothing reaches GitHub until a draft is published whole.
- **Claude-assisted editing** — select text (or take the whole document), describe the change,
  and the rewrite streams into the document through the local `claude` CLI, reusing whatever
  account is signed in on the machine: your own subscription, no bundled key. A gist can be
  dragged onto the instruction as context, runs are cancellable, and a stopped or failed run
  restores what was there.
- **Auto-update** — installed apps check the newest published release on startup and update in
  the background.

### Installing

Builds are currently unsigned:

- **Windows** (`.exe`, x64) — SmartScreen warns on first run: choose _More info_ → _Run anyway_.
  Auto-update works.
- **macOS** (`.dmg` / `.zip`, universal) — Gatekeeper only opens the app via right-click →
  _Open_, and auto-update stays off until the build is signed.
