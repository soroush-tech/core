## Soroush Editor v0.4.0

Repairs auto-update and puts it in view: updates actually install now, and a banner
in the app says when one is ready.
([#343](https://github.com/soroush-tech/core/pull/343))

### Fixed

- **Auto-update never worked** - the update manifest (`latest.yml`) named the installer with
  dashes while the release asset carried dots, so every update check ended in a 404 and the
  app silently stayed on its version. The cause: electron-builder's default artifact names
  contain spaces, the manifest records their space-to-dash form, and GitHub renames uploaded
  asset files space-to-dot. Artifacts are now named without spaces
  (`Soroush-Editor-Setup-<version>.exe`), so the manifest, the built file and the release
  asset finally agree. Installs of 0.3.0 and earlier cannot self-update across this fix -
  install this version from the release page once, and updates flow from here on.

### Added

- **In-app update banner** - when a new version has finished downloading, an info-colored bar
  appears across the top of the window naming it, with an **Update** button that restarts
  straight into the new version. Dismissing the banner (or just ignoring it) is fine too:
  the update still installs on quit, and a dirty document keeps its unsaved-changes prompt
  either way.
