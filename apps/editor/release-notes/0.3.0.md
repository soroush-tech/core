## Soroush Editor v0.3.0

Adds a Help menu with an About dialog.
([#342](https://github.com/soroush-tech/core/pull/342))

### Added

- **Help > About Soroush Editor** - one message box, identical on every platform, showing the
  app version and the Electron, Chromium and Node runtime versions a bug report needs. The
  dialog is owned by the focused window when one is open, so it cannot be lost behind it.
